# Zenoh Hello World

A minimal end-to-end example showing how to expose and consume a WoT Thing over **Zenoh** using WoTPy.

The example covers:
- **Property read** (get current value)
- **Property write / publish** (set a new value)
- **Property observe / subscribe** (stream live changes)
- **Action invocation**
- **Event subscription**

## Files

| File | Description |
|---|---|
| `server.py` | Exposes the Thing (producer / publisher) |
| `client.py` | Consumes the Thing (consumer / subscriber) |
| `hello-world-td.json` | Standalone Thing Description (reference) |
| `requirements.txt` | Python dependencies |

## Prerequisites

### 1 – Zenoh router

A Zenoh router must be reachable. The easiest way is Docker:

```bash
docker run --rm -p 7447:7447/tcp eclipse/zenoh
```

### 2 – Python environment

```bash
pip install -r requirements.txt
# or, inside the wotpy dev tree:
pip install -e ../../
```

## Running

### Terminal 1 – start the server (Thing)

```bash
python server.py
# Custom router:
python server.py --router tcp/192.168.1.10:7447
```

On startup the server prints the Zenoh topics it listens on and serves the
TD catalogue at `http://localhost:9090`.

### Terminal 2 – run the client (Consumer)

```bash
python client.py
# Custom router / catalogue:
python client.py --router tcp/192.168.1.10:7447 --catalogue http://localhost:9090
```

The client will:
1. Fetch the TD from the catalogue
2. **Read** the `message` property
3. **Write** a new value to `message`
4. **Observe** `message` for 5 seconds while writing three updates
5. **Invoke** the `greeting` action
6. **Subscribe** to the `newMessage` event for 3 seconds

## Thing Description

The TD is auto-generated by WoTPy and served at `http://localhost:9090`.
A reference copy is included in `hello-world-td.json`.

### Zenoh topic structure (generated by WoohPy)

```
<servient_id>/property/requests/<thing_title>/<property_name>   ← read / write
<servient_id>/property/updates/<thing_title>/<property_name>    ← observe
<servient_id>/action/requests/<thing_title>/<action_name>       ← invoke
<servient_id>/event/updates/<thing_title>/<event_name>          ← subscribe
```

The `<servient_id>` defaults to `wotpy` and `<thing_title>` is the slugified
`title` field from the TD (e.g. `helloworldzenoh`).
